# Glosario para el equipo (y para explicar al agricultor)

| Término | Explicación simple |
|---|---|
| **Evapotranspiración (ET)** | Agua que sale del campo hacia el aire: evaporación del suelo + transpiración de las plantas. Es la "sed" del cultivo. |
| **Anomalía de humedad del suelo** | Cuánto más seco/húmedo está el suelo comparado con lo normal para esa época. |
| **NDVI** | Índice de "verdor" (−1 a 1). Alto = vegetación vigorosa; bajo = suelo desnudo o planta estresada. |
| **Suelo desnudo** | Periodo sin cobertura: más erosión, más evaporación, menos materia orgánica. |
| **Riesgo de helada** | Días con temperatura mínima ≤ 0 °C, sobre todo en etapas sensibles. |
| **Grados-día de crecimiento (GDD)** | Calor acumulado útil para el desarrollo del cultivo. |
| **Balance hídrico** | Lluvia (entradas) − ET (salidas) ± escorrentía/infiltración. |
| **Fijación de nitrógeno** | Leguminosas que, con bacterias, aportan N al suelo. |
| **Cultivo de cobertura** | Se siembra para proteger y mejorar el suelo, no para cosecha. |
| **Rotación** | Secuencia planificada de cultivos en un mismo lote. |
| **Ciclo de plagas** | Plagas/enfermedades que se acumulan si se repite la misma familia de cultivo. |
| **Fusión de datos** | Combinar fuentes distintas en una sola vista coherente. |
