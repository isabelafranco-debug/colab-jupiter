# Plan de hackathon (adaptable a 48 h)

## Roles sugeridos
| Rol | Responsabilidad |
|---|---|
| Datos NASA | Descarga, cache, armonización, metadatos |
| Modelado | Indicadores, puntaje, incertidumbre, sensibilidad |
| Agronomía/Dominio | Parámetros de cultivos, validación, riesgos locales |
| Frontend/UX | App/mapa, lenguaje para agricultores, escenarios |
| Comunicación | Storytelling, video, presentación, README |

## Cronograma
| Bloque | Meta |
|---|---|
| Horas 0–4 | Elegir región piloto y 3 fuentes NASA; definir criterios |
| 4–16 | Pipeline de datos + indicadores funcionando |
| 16–28 | Motor de rotaciones + tarjetas explicativas |
| 28–38 | UI, mapa/escenarios, pruebas con "usuario agricultor" |
| 38–44 | Incertidumbre, vacíos y riesgos; pulir |
| 44–48 | Video, README, envío, ensayo de la demo |

## Reglas de oro
- Región piloto **pequeña y bien explicada** > cobertura global superficial.
- Tener siempre una **versión demostrable** (datos sintéticos de respaldo si falla la API).
- Congelar funciones 6 h antes de entregar.
